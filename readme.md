SLOPE CE — v0.18

A "vibe-coded" port of Slope for the TI-84 Plus CE calculator. The original Slope was made by Rob Kay and published by Y8 Games.



Player design / reference: imatree (https://www.cemetech.net/users/imatree)



coded with the help of ChatGPT 6 Astra, Claude Sonnet 5.5, and Z.ai's GLM 5.3.



Requirements

TI-84 Plus CE

OS 5.5.1 or later: install arTIfiCE (https://yvantt.github.io/arTIfiCE/). Earlier OSes run ASM natively.

\~40-50 KB free RAM — archive your other programs first

Date \& time set (MODE → date/time) — Daily Runs use it

Install

Send EVERYTHING in the zip to the calculator with TI Connect CE, including the
clibs folder.

Run from Cesium or with Asm(.

Progress is stored in the SLPESAVE AppVar. Don't delete it



Controls

Arrows — steer / navigate

2nd or Enter — select

1–6 — quick select on the title screen

Clear — back



Troubleshooting

ERR: MEMORY — free up RAM (archive programs), then relaunch

Errors on launch — the libraries weren't sent; resend the whole zip

There are secrets. Two, currently: one for cheats, one for "lore".

Estimated 30 FPS average, may drop during graphically heavy sections of the world.
